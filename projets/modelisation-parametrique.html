Modélisation par script sous ANSYS APDL

Projet académique individuel, ISBA-TP, 2025/2026

J'ai modélisé une structure BA (radier, voiles, plancher, toiture, poteau) entièrement en ligne de commande :

  • coques SHELL181 pour les parois, poutre BEAM188 pour le poteau ;
  • cas de charges enregistrés séparément, puis recombinés ;
  • enchaînement statique, modale, spectrale par direction (CQC), puis combinaisons sismiques ;
  • contrôle des réactions d'appui par un calcul manuel avant toute analyse dynamique.

J'ai réutilisé cette chaîne pour le modèle de recoupement du bâtiment auxiliaire de sûreté.

Fait clé

Réaction verticale sous poids propre identique au calcul manuel

Génération paramétrique et comparaison de variantes (Grasshopper + Robot)

Stage ingénieur études, Société tunisienne de sidérurgie El Fouladh, 02/2022 – 06/2022, Tunis
Rhinoceros (Grasshopper) · Robot Structural Analysis

Pour la couverture mobile d'un terrain de tennis :

  1. j'ai piloté la forme par quelques paramètres dans Grasshopper (portée, flèche, courbure des arcs) ;
  2. j'ai retenu trois formes selon l'orientation du terrain et les vents dominants ;
  3. j'ai généré automatiquement le maillage de barres sur ces formes ;
  4. j'ai dimensionné quatre variantes de structure sous Robot, puis je les ai comparées sur leur poids.

Automatisation de la documentation sous Revit (Dynamo)

Stage ingénieur BIM, automatisation de processus, Groupe Studi International, 06/2024 – 08/2024, Tunis
Revit · Dynamo · Excel

J'ai écrit trois scripts Dynamo pour retirer une tâche répétitive aux projeteurs :

  • annotation des poutres, classées selon leur orientation ;
  • annotation des poteaux, numérotés selon leur position ;
  • import d'un tableau Excel, pour traiter les poutres continues que le premier script ne gérait pas.

Je les ai livrés via Dynamo Player, avec des paramètres simples, pour un usage sans ouvrir Dynamo.
